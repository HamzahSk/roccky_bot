## Akar masalah "Invalid media type"
`prepareWAMessageMedia` di Baileys (`lib/Utils/messages.ts`) melempar `Boom('Invalid media type', 400)` sebagai cabang terakhir `generateWAMessageContent` — terpicu saat objek konten tidak punya `text` valid **dan** tidak punya key media valid, biasanya karena ada key media (`image`/`document`/`video`/`header` dst.) bernilai `null`/`undefined`. Ditambah `lib/Components/ErrorHandler.js` lama memanggil `process.exit(1)` untuk error tak dikenal → **satu sendMessage gagal mematikan seluruh bot**.

## Temuan riset Baileys (poin 2)
- WhatsApp **tidak merender Markdown di sisi server**; `*tebal*`, `_miring_`, `~coret~`, `` ```monospace``` `` dirender klien (dokumentasi resmi "Formatting Text", isu #1918). Cara valid & terbaru untuk teks AI: langsung `sock.sendMessage(jid, { text })` — **tidak perlu** dibungkus interactive/card.
- Untuk header interactive/native flow: `hasMediaAttachment` harus sinkron dengan ada-tidaknya key media, dan header/body tidak boleh punya field `nullish` (HTTP 400).
