## 3. Helper Parser Markdown (`lib/Function/markdown.js`)

Fungsi utama: `Func.formatMarkdown(text, opts)` → string teks siap kirim; `Func.parseAIMessage` (alias, dgn `asSegments:true`), `Func.parseMarkdownSegments`, dan `Func.sendAI` (kirim + try-catch fallback). Logika inti:

```js
// a) Code block: buang header bahasa, pertahankan ``` bawaan WA
const FENCE_ANY_REGEX = /^(`{3,}|~{3,})(\w[\w-]*)?\s*$/
const cleanFenceLine = (line) => (line.match(FENCE_ANY_REGEX) ? '```' : line)

// b) Tabel -> box-drawing monospace
┌──────┬───────┬────────┐
│ Nama │ Nilai │ Status │
├──────┼───────┼────────┤
│ Budi │ 85    │ Lulus  │
└──────┴───────┴────────┘

// c) Pembersihan escape & penyeimbang marker
const UNESCAPE_MAP = /\\([*_~`\[\]()#+\-.|>\\])/g   // \* -> *
out = balanceMarker(out, '*')                       // ganjil -> escape terakhir
out = linkToPlain(out)                              // [t](u) -> "t (u)"
```

Contoh penerapan pada pengiriman pesan AI (dipakai di `plugins/ai/_chatbot.js` & `lib/Scraper/_chatbot.js`, duplikasi `parseMarkdown`+`richResponse` dihapus):

await sock.sendMessage(m.chat, { delete: thinking.key })

try {
